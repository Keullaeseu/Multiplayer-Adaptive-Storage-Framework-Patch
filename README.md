# Multiplayer Adaptive Storage Framework Patch

A RimWorld Multiplayer compatibility patch for [Adaptive Storage Framework](https://steamcommunity.com/sharedfiles/filedetails/?id=3033901359).

This mod is designed to improve multiplayer synchronization when playing with the [Adaptive Storage Framework](https://steamcommunity.com/sharedfiles/filedetails/?id=3033901359) mod and RimWorld Multiplayer.

## Features

- Adds multiplayer compatibility for [Adaptive Storage Framework](https://steamcommunity.com/sharedfiles/filedetails/?id=3033901359).

## Requirements

- RimWorld
- [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077)
- RimWorld Multiplayer
  - [GitHub version](https://github.com/rwmt/Multiplayer) or [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=2606448745) version
- [Adaptive Storage Framework](https://steamcommunity.com/sharedfiles/filedetails/?id=3033901359)

The host and every connected player must use compatible versions of all required mods.

## Installation

### Steam Workshop

Subscribe to the required mods and add them to your RimWorld mod list in the following order:

1. Harmony
2. Core
3. Royalty, Ideology, Biotech, and Anomaly, if applicable
4. RimWorld Multiplayer
5. [Adaptive Storage Framework](https://steamcommunity.com/sharedfiles/filedetails/?id=3033901359)
6. [Multiplayer Adaptive Storage Framework Patch](https://github.com/Keullaeseu/Multiplayer-Adaptive-Storage-Framework-Patch/releases/latest)

The patch should load after both RimWorld Multiplayer and [Adaptive Storage Framework](https://steamcommunity.com/sharedfiles/filedetails/?id=3033901359).

### Manual Installation

1. Download the latest release from the [**Releases**](https://github.com/Keullaeseu/Multiplayer-Adaptive-Storage-Framework-Patch/releases/latest) section.
2. Extract the mod folder into your RimWorld `Mods` directory.
3. Enable the required mods in RimWorld.
4. Use the recommended load order listed above.
5. Make sure every multiplayer player has the same mod list, configuration, and load order.

## Multiplayer Usage

All players should have the following mods installed and enabled:

- RimWorld Multiplayer
- [Adaptive Storage Framework](https://steamcommunity.com/sharedfiles/filedetails/?id=3033901359)
- [Multiplayer Adaptive Storage Framework Patch](https://github.com/Keullaeseu/Multiplayer-Adaptive-Storage-Framework-Patch/releases/latest)
- All required Adaptive Storage Framework dependencies

The host and all connected clients should use the same:

- RimWorld version
- RimWorld Multiplayer version
- Adaptive Storage Framework version
- Multiplayer Adaptive Storage Framework Patch version
- Mod configuration
- Mod load order

Do not add, remove, update, or reorder mods while players are connected to the same multiplayer session.

## Compatibility

This patch is intended to provide multiplayer compatibility for [Adaptive Storage Framework](https://steamcommunity.com/sharedfiles/filedetails/?id=3033901359).

It does not replace:

- [RimWorld Multiplayer](https://steamcommunity.com/sharedfiles/filedetails/?id=2606448745)
- [Adaptive Storage Framework](https://steamcommunity.com/sharedfiles/filedetails/?id=3033901359)

## Known Limitations

- Compatibility may be affected by future RimWorld updates.
- Compatibility may be affected by future updates to RimWorld Multiplayer or Adaptive Storage Framework.
